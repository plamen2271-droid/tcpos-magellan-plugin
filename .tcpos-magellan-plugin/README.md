# BarcodeReaderMagellan.DroidPos

This is a Xamarin.Android Class Library that mimics the TCPOS Zebra MP7000 barcode reader plugin,
but targets Datalogic / Magellan (Sunmi Flex 3).

## Build in GitHub Codespaces
1. Open this repo in Codespaces.
2. Wait for the container to finish installing (mono + msbuild).
3. Run:

   ```bash
   cd BarcodeReaderMagellan.DroidPos
   msbuild /t:Rebuild /p:Configuration=Release
   ```
